GPT Image 2.5 Flare 接入说明

通过 HTTP 异步提交图像生成与参考图编辑，轮询任务后取得对象存储图片 URL。本文保留工作台的尺寸、比例、质量、风格、背景及参考图参数，按 Sub2API 异步生图指南适配调用流程。

AIOSS 已由站点开通异步生图对象存储；本页示例使用异步提交 → 同密钥轮询 → 读取存储 URL。2026-10-16 已实测文生图：提交返回 202，约 35 秒后任务 completed，原始返回地址包含 /annex/images/，免密下载返回 200，确认为 1024×1024 PNG 图片。参考图编辑及 H3 视频生成未实测。

身份验证与端点

02 / AUTHENTICATION

提交和查询均携带 Authorization: Bearer <API_KEY>，查询必须使用提交任务的同一把密钥。密钥作为调用方参数，不写入本文。

基础地址已经包含 /v1。文生图发送 JSON；参考图编辑使用 multipart/form-data，由 HTTP 库生成包含 boundary 的请求头。异步接口沿用原生图请求体；对象存储 bucket、凭据及 CDN 域名由站点配置，不放入客户端请求体。

尺寸与比例

04 / SIZE & ASPECT RATIO

直接 HTTP 请求只接收最终像素字符串 size。工作台的 outputSize 和 aspectRatio 在请求前完成换算。

比例1K2K4K
1:11024x10242048x2048不可选 · 总像素超限
3:21536x10242048x1360不可选 · 总像素超限
2:31024x15361360x2048不可选 · 总像素超限
16:91824x10242048x11523840x2160

4:31360x10242048x1536不可选 · 总像素超限
3:41024x13601536x2048不可选 · 总像素超限

像素按 16 的倍数四舍五入，因此实际宽高比可能略有偏差。4K 档按最长边 3840px 计算；方形 3840x3840 超过项目像素上限，不会出现在工作台可选组合中。

自动布局

选择自动时，工作台使用 outputSize=auto、aspectRatio=auto，并清除自定义尺寸；最终请求不发送 size。

希望严格指定输出尺寸时，使用表中的具体像素值。

自定义尺寸

  • 宽、高规整到 16 的倍数。
  • 工作台最长边 ≤ 3840px。
  • 长边 ÷ 短边 ≤ 3。
  • 总像素介于 655,360 与 8,294,400，含边界。
  • 合法自定义尺寸优先于档位与比例。
尺寸换算规则及当前实现差异

1K：正方形为 1024×1024，其他比例固定短边为 1024，长边按比例计算后取最近的 16 倍数。2K / 4K：固定长边为 2048 / 3840，短边按比例计算后取最近的 16 倍数。

当前前端自定义尺寸最大边长为 3840；后端 resolveGptImageRequestSize 对自定义尺寸的规整上限为 4096。本文配置器沿用前端 3840 的规则。后端对“档位 + 比例”换算结果没有执行同样的像素过滤，因此接入方应在计算后应用上表的工作台校验。

自定义输入先四舍五入到 16 倍数，再将每条边截到上限，然后校验比例和总像素；合法值覆盖预设尺寸，无效值在现有后端会退回预设尺寸。

参考图设置

05 / REFERENCE IMAGES
  1. 添加参考图后切换到异步编辑端点本页无参考图调用 images/generations/async，有参考图调用 images/edits/async。参考图来源沿用工作台：上传、拖入、剪贴板粘贴，以及从本地或 S3 素材中读取。
  2. 按顺序重复提交 image 文件字段1 张参考图提交 1 个 image，多张提交多个同名 image。示例采用 PNG 文件；替换为其他格式时，文件名、MIME 和字节内容应一致。素材 URL 在项目中先读取为文件内容，再作为文件上传。
  3. 在 prompt 中说明每张图的作用例如：“图片1作为主体，保留花瓶的形状与材质；图片2作为环境参考，采用其光线与背景。”项目没有单独的参考强度、参考权重或角色字段。画布会在提示词前补充“参考图片编号：图片1、图片2……”以描述引用关系。
  4. 输出尺寸独立设置非自动布局下，首次上传参考图时，工作台会根据第一张图寻找最近的可选比例；不会把该图原始宽高直接作为请求 size。自动布局时不执行此比例选择。最终输出由显式 size 或服务端自动布局决定。

沿用当前项目的参考图预处理

以下为项目上传策略，不是 AIOSS 的服务限制。直接对接 HTTP 时，可在调用方按需要复用。

项目设置当前行为
数量Flare 内置上限为 16 张，由模型配置的 maxRefImages 控制；素材库单次导入最多 5 张，可继续追加。
小文件≤ 1.5 MiB 时直接使用原图，不压缩。
较大文件> 1.5 MiB 时尝试压缩：长边 ≤ 2560px、总像素 ≤ 5,000,000，保持原始比例。PNG / WebP 转为 WebP，质量 0.90；其他类型转为 JPEG，质量 0.86。
保留原图条件压缩结果大小 ≥ 原文件的 98% 时保留原图；压缩失败时也可能使用原始内容或回退结果。上述缩放值属于压缩目标，并非每张最终参考图的硬性尺寸上限。
单图检查工作台检查处理后的文件大小 ≤ 10 MiB（10 × 1024 × 1024 字节）。
项目后端请求体项目本地任务接口还限制 JSON 请求体长度为 10 × 1024 × 1024 个字符，Base64 会增加体积；多图可能先达到此限制。直接调用 AIOSS 的 multipart 接口不经过这一层检查。
缓存与去重按原文件 SHA-256 缓存处理结果；工作台按图片 ID 去重。缓存命中标记与压缩比例不作为 HTTP 参数提交。

异步轮询与对象存储地址

07 / RESPONSE

以下是协议示意，URL 与任务 ID 均需替换为实际返回值。提交获得 202 代表已受理；status=completed 才能读取生成结果。

POST · 202 Accepted
{
  "id": "imgtask_example",
  "task_id": "imgtask_example",
  "object": "image.generation.task",
  "status": "processing",
  "poll_url": "/v1/images/tasks/imgtask_example"
}

轮询顺序

  1. 保存 task_id，没有时取 id。使用同一把密钥 GET 查询端点。
  2. processing 时继续查询；默认间隔 3 秒，可按 Retry-After 调整。
  3. completed 时读取 result.data[].url；顶层 image_url 是第一张图片的快捷字段。
  4. failed 时读取 error.message 与 http_status。查询 HTTP 200 本身不代表生成成功。
GET · 任务完成后的对象
{
  "id": "imgtask_example",
  "task_id": "imgtask_example",
  "object": "image.generation.task",
  "status": "completed",
  "http_status": 200,
  "image_url": "https://cdn.example.com/images/imgtask_example-0.png",
  "result": {
    "created": 1792022400,

存储配置与链接有效期

对象存储配置由 AIOSS 服务端管理，客户端仅提交生图参数。服务端设置 public_base_url 时，结果为该域名下的对象直链；留空时返回带签名的临时 URL。签名有效期由 presign_expiry_hours 决定，官方配置示例为 24 小时，AIOSS 实际值以站点配置为准。

任务的 expires_at 表示任务记录到期时间，不能用它推算 CDN URL 的有效期。Sub2API 任务记录自最后一次状态更新起保留 24 小时；图片能保留多久还取决于对象存储的文件策略。

给 H3 提供参考图时，直接使用 task.result.data[0].url 或 task.image_url，保留完整签名参数，并确保 H3 上游能在排队、读取期间访问。详见视频参考图接入说明。

// Node.js · task 是轮询得到的完整任务对象。
import { writeFile } from 'node:fs/promises';

async function saveImage(task, filename = 'output.png') {
  if (task.status !== 'completed') throw new Error('图片任务尚未成功完成');
  const url = task.result?.data?.[0]?.url || task.image_url;
  if (!url) throw new Error('任务结果无图片 URL');
  // 下载对象存储 URL 时不附加生图 API 密钥。
  const response = await fetch(url);
  if (!response.ok) throw new Error(`下载失败: ${response.status}`);
  await writeFile(filename, Buffer.from(await response.arrayBuffer()));
  return filename;
}

保存函数返回本地文件名；给 H3 传参仍需原始公网 URL。网页端请求 AIOSS 或下载图片时，跨域权限由对应服务决定；H3 服务端读取参考图还需单独满足公网可访问条件。

多图与任务恢复

08 / EXECUTION

一次生成 1–4 张

沿用工作台的并行方式：创建 1–4 个独立异步任务，每个请求重复提交参数及参考图。分别保存任务 ID，并查询各自结果。

调用方控制提交并发与查询频率；不要因任务仍在 processing 就重复 POST。

保留 ID 后恢复查询

Sub2API 单个任务最多执行 30 分钟。示例将调用方轮询等待时间设为 30 分钟；等待超时或查询网络中断时，保留任务 ID，之后使用同一把密钥恢复 GET 查询。

异步端点拒绝 stream=true。对象存储转存失败时任务会标记 failed，需读取具体错误后处理。

// 调用方参数 apiKey；generateImage 使用上方 JavaScript 示例。
// 参考图模式时，按同样方式给每次调用传入 referenceFiles。
const parallelCount = 3; // 与工作台一致：1–4
const results = await Promise.allSettled(
  Array.from({ length: parallelCount }, () => generateImage(apiKey, prompt))
);

// 已保存任务 ID 时可恢复查询，不必重新提交生图。
// const task = await waitForImageTask(apiKey, savedTaskId);
// Python：task = wait_for_image_task(api_key, saved_task_id)

提交超时不代表任务未创建，避免自动重发产生重复任务。本文示例仅生成调用代码；浏览器页面本身不提交生图请求。

常见问题

09 / TROUBLESHOOTING
现象检查与处理
401 / 403检查 Bearer 密钥、账户可用状态及该密钥对固定模型的访问权限；保留服务端具体错误消息。
400 或参数错误检查模型名称、尺寸合法性和字段枚举。style 自动时应省略；项目质量使用 auto / high / medium / low。
参考图没有生效使用 /images/edits/async，以 multipart 上传真实文件；多张图重复 image 字段；核对提示词中的图片编号和文件顺序。
413 / 文件体积过大减少图片数量或大小。若经过项目任务接口，还需核对包含 Base64 的整体 JSON 体积；直接调用 AIOSS 时按其实际限制处理。
429 或繁忙响应按服务端说明与 Retry-After（如有）控制重试间隔，降低调用方同时进行的请求数。
提交 /async 返回 404检查路径和站点的异步存储配置是否完整，密钥所属平台须为 OpenAI 或 Grok；保留响应中的具体错误。开关已开启但 S3 配置不完整时，仍可能返回 async image tasks are not enabled。
查询任务返回 404核对 task_id、提交时使用的同一把 API 密钥以及任务记录是否到期；同一用户的另一把密钥也不能查询该任务。
返回 HTML / 地址错误检查完整地址，避免 /v1/v1。poll_url 已含 /v1，应与站点根地址解析；记录网关返回的状态和内容。
504 / 超时 / 网络中断保留错误和请求记录，检查服务端状态后决定是否重试。超时并不说明服务端没有完成处理；重发可能产生新的生成任务。
202 响应中没有图片202 仅表示受理，保存任务 ID 后轮询；status=completed 时读取 result.data[0].url，或顶层 image_url。
查询 HTTP 200，但图片生成失败检查 status 是否为 failed，以及 error.message / http_status。生成或对象存储转存错误均需以任务对象判断。
异步请求提示不支持流式省略 stream 和 partial_images，不向 /async 提交 stream=true。
任务 completed，但图片 URL 返回 404核对站点 public_base_url 是否指向实际图片存储桶的公开域名，以及对象键前缀与 CDN / 反向代理的路径映射。任务完成不等于外链可公开读取；用无需密钥的 GET 确认返回真实图片后，再将地址交给 H3。
H3 无法读取生图地址确认已等到 completed，使用原始对象存储 URL 并保留签名参数；核对公网读取权限与签名有效期，不使用本地文件或缓存引用。
其他参数现有链路未发送 seed、negative_prompt、参考权重、strength、input_fidelity 或 mask。本文不为这些字段定义接入行为。
